#Python File Handling – Product Data Management

Developed a Python-based file handling project to manage product information and sales data using CSV, JSON, and TXT files.

Implemented functions to load, add, and update product sales data, details, and descriptions using Python dictionaries.

Built input validation to verify SKU length, ensure 14 days of sales data, and check required product information.

Automated data storage by writing updated records back to CSV, JSON, and TXT files, with automatic folder creation using Python's os, csv, and json modules.
